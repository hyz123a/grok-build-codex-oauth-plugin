---
name: setup
description: Configure selectable Grok `codex-*` models for the local OAuth proxy.
---

Run `grok-codex-oauth setup` with the shell tool.
Then run `grok-codex-oauth ensure-daemon`.
If the user is logged in, run `grok-codex-oauth models sync`.
Tell the user to open `/model` and select a `codex-*` entry.
